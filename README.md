# Women Entrepreneur Website

A professional static website inspired by the supplied reference layout, but intentionally redesigned with a different cream / plum / rose / gold visual identity.

## Included
- Responsive Home page
- Courses / Programs sections
- Student registration UI
- Automatic Student ID generation
- Unique Referral Code generation
- Referral code field during registration
- Student login demo
- Slide-out navigation
- Logo asset
- Mobile responsive layout

## Important about Student IDs and referrals
This package is a **static frontend** so it can be uploaded directly to GitHub Pages. The demo uses browser `localStorage`, which means accounts are only stored in the visitor's browser.

For a real website where multiple users can register and referral relationships are shared across devices, connect the forms to a backend/database such as Supabase, Firebase, or a custom server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders while preserving the `assets` folder.
3. Make sure `index.html` is in the repository root.
4. Enable GitHub Pages from repository Settings → Pages.
5. Select the branch/folder containing `index.html`.

## Branding
Replace `assets/logo.png` whenever you want to change the logo. The website will automatically use the new image.
