# Women Entrepreneur — iOS Updated

GitHub-ready frontend.

## Structure
- index.html
- styles.css
- script.js
- assets/

## Main behavior
- Public landing page does NOT show personal profile data.
- Work/skill categories are visible before login.
- User must register first.
- Each registered user gets a unique User ID and Referral Code.
- Login shows that logged-in user's own profile only.
- Profile supports photo upload, JPG download, edit and logout.
- Data is stored in browser localStorage for this frontend demo.

## GitHub Pages
Upload all files to the repository root and keep `assets` as a folder.
