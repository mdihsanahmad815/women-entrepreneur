## Features
- Login / Sign Up
- Profile is hidden until login
- Registered user's own Name, Gmail, Phone, User ID, Referral Code and Joined Date
- Profile photo upload
- Download JPG
- Edit Profile / Logout
- Multiple work-skill category selection
- Responsive iPhone/mobile design
- English/Bangla button
- Women Entrepreneur logo included

### Important
This version uses browser localStorage for a front-end demo. For real permanent multi-user accounts, a backend/database/authentication service is required.
