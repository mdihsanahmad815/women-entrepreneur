# Women Entrepreneur Website

Professional pastel/purple Women Entrepreneur static website.

## Files
- `index.html` — full website and profile UI
- `styles.css` — responsive design
- `script.js` — profile, photo upload/download, categories, registration/login demo
- `assets/logo.png` — Women Entrepreneur logo

## Profile features
- Profile photo upload
- Download current profile picture as JPG
- Name, User ID, Gmail, phone, referral code and joined date
- 9 requested work categories with multi-select
- Referral code copy button
- Responsive mobile layout

## GitHub Pages
Upload all files/folders to the repository root. Keep `assets/logo.png` inside the `assets` folder. Then enable GitHub Pages from Settings → Pages and select the `main` branch and `/ (root)`.

This is a frontend demo; account data is stored in the browser using localStorage. A real multi-user login/database needs a backend.
